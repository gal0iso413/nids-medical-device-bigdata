# 모델 3 「우리 기업군 동향」 이용 안내

> **대상:** 의료기기 관련 기업·기관 이용자 및 간담회 참석자  
> **화면:** 혁신 시안 `innovation/class3.html` (권장) · 기존안 `class_3/`  
> **데이터:** 현재 프로토타입은 **생성 예시**입니다. 아래 산출 정의는 화면이 말하는 의미와 **향후 운영 시 적용할 계산 방식**을 정리한 것입니다. 표시 수치로 사업·정책 결정을 하지 마세요.

## 1. 이 시스템이 하는 일 / 하지 않는 일

| 하는 일 | 하지 않는 일 |
|--------|-------------|
| 회사명 없이 **업종·권역·품목군**으로 비교군(해당 기업군)을 만듦 | 특정 업체 검색·순위·실명 공개 |
| 비슷한 기업군 대비 **위치·변화·확인할 질문** 제공 | 이상거래 탐지(모델 1) · 위험등급(모델 2) |
| 관심 **품목명**의 집계 통계·진단 | 품목 허가·UDI·모델 **등록정보 색인(index)** |
| 소수 기업군은 숨기거나 추이를 제한 | 수요 예측·투자·사업 성공 보장 |

한 줄로: **「나와 비슷한 기업의 위치와, 다음에 무엇을 볼지」**를 보는 화면입니다.

## 3. 이용 순서 (혁신 시안)

### ① 비교 기준 고르기

1. **업종** — 제조업 / 수입업 / 판매(임대)업 / 의료기관 / 기타  
2. **주 활동 권역** — 수도권 / 비수도권 / 전국  
3. **관심 품목군** — 분류 체계의 품목군 (예: `B2. 임상화학검사기기`)  
4. **「기업군 리포트 생성」** 클릭  

회사명·사업자번호는 입력하지 않습니다.

**품목군 ≠ 품목명**

- 기업군 단계: **품목군**(분류)  
- 이어보기 단계: **품목명**(개별 품목 집계)

### ② 기업군 리포트 읽기

위에서 아래로:

| 구간 | 무엇을 보나 |
|------|-------------|
| **거시** | 해당 기업군 규모·활동 한 줄 요약 |
| **쉬운 사실** | 위치(상·중·하 구간) · 월별 거래 활동 추이 |
| **진단** | 관측 → 해석 → 유의점 (사실과 해석을 분리) |
| **반응** | 품목군 검토 지도 · 확인할 질문 · (참고) 기업군 유형 |

### ③ (선택) 관심 의료기기 알아보기

1. **「관심 의료기기 알아보기」**  
2. 추천 검색어 또는 품목명 입력  
3. **「품목 통계 보기」** → 거시 · 통계 · 진단  

이 화면은 **시장 집계 요약**이지, 허가·UDI 목록 조회가 아닙니다.

### 공개가 막히거나 추이가 없을 때

| 예시 조건 | 화면 |
|-----------|------|
| `기타` + `비수도권` | 공개 제한 (기업·기관 수가 공개 기준 미만인 예시) |
| `기타` + `수도권` | 위치 지표는 보이나 **월별 추이 숨김**(이력 짧음) |

권역을 `전국`으로 넓히거나 조건을 완화해 다시 시도하세요.

## 4. 지표(인덱스) 사전 — 의미와 산출

### 4.1 공통 원칙

1. **공급내역 보고 데이터**를 기준으로 집계합니다. (프로토타입은 합성값)  
2. 공개 화면에서는 정확한 순위·개인 값 대신 **구간(밴드)** 을 씁니다.  
3. 소수 셀·지배적 1~2개 업체 비중 등은 **공개 억제** 대상입니다. (시안 기본: 비교군 최소 `k ≥ 5`)  
4. **증감(변화)** 과 **현재 규모**는 다른 이야기입니다. 늘었다고 해서 규모가 크다는 뜻이 아닙니다.

---

### 4.2 기업군 규모

| 항목 | 설명 |
|------|------|
| **의미** | 선택한 업종·권역·품목군 조건에 맞는 기업·기관 수 |
| **표시** | 예: `40~49개` (정확한 개수 대신 구간) |
| **산출(운영 시)** | 조건에 해당하는 고유 업체(내부 일련번호) 수를 센 뒤, 공개 규칙에 따라 반올림·구간화 |
| **질문 대비** | “내 회사 한 곳의 숫자가 아니다. 비교군 전체 규모다.” |

---

### 4.3 위치 구간 (상위 25% / 중간 50% / 하위 25%)

화면의 지표값(거래 활동 변화, 품목 폭 등)은 모두 **선택한 조건의 해당 기업군 집계**입니다.  
옆에 붙는 「상위 25% / 중간 50% / 하위 25%」는 **그 기업군 안의 회사 순위가 아닙니다.**

| 항목 | 설명 |
|------|------|
| **의미** | **해당 기업군의 집계 지표**가, **더 넓은 전체(비교 분모)** 분포에서 어디에 있는지 |
| **대상(분자)** | 업종·권역·품목군으로 만든 **그 기업군 하나**의 지표값 (예: 기업군 평균 거래 활동 변화율) |
| **비교 분모** | 같은 지표를 같은 방식으로 구한 **전체(또는 더 넓은 기준 집단)** — 예: 동일 업종 전체 기업군·전체 기업 분포 |
| **표시** | 정확한 퍼센타일·순위 대신 세 구간만 |
| **산출(운영 시)** | (1) 해당 기업군 집계값 계산 → (2) 비교 분모의 같은 지표 분포를 정렬 → (3) 하위 25% · 중간 50% · 상위 25% 경계에 그 집계값이 어디에 속하는지 표시 |
| **왜 순위가 없나** | 정확한 순위·개인 값은 식별·영업비밀 위험이 있어 구간만 공개 |
| **질문 대비** | “이 기업군 **내부** 1등”이 아님. “이 기업군이 **전체 대비** 어디쯤인가” |

**잘못된 읽기:** 기업군에 속한 회사들을 줄 세워 그중 한 곳의 위치  
**맞는 읽기:** 선택된 기업군(집계) vs 전체 데이터(넓은 분포)

> 나중에 인증 **「내 회사」** 모드가 생기면, 그때는 “내 회사 vs 같은 기업군 동료” 퍼센타일을 **별도**로 둘 수 있습니다. 지금 공개 시안의 위치 구간은 그 모드가 아닙니다.

### 4.4 거래 활동 변화

| 항목 | 설명 |
|------|------|
| **의미** | 최근 거래 **보고 건수(횟수)** 가 이전 기간 대비 얼마나 변했는지 |
| **화면 정의문** | 최근 3개월 거래 보고 횟수의 이전 기간 대비 변화 |
| **표시** | 예: `5~10% 증가` (세부 %를 구간화) |
| **산출(운영 시)** | \(\displaystyle \text{변화율} = \frac{A_{\text{최근3개월}} - A_{\text{직전3개월}}}{A_{\text{직전3개월}}}\) 여기서 \(A\) = 해당 기업군(또는 품목)의 월별 거래 보고 건수 합 |
| **주의** | 보고 습관·신규 등록·공휴일 등으로도 변할 수 있음. “매출 증가”와 동일하지 않음 |

### 4.5 취급 품목 폭

| 항목 | 설명 |
|------|------|
| **의미** | 해당 기업군에서 활동이 확인된 **품목명** 종류의 넓이 |
| **표시** | 예: `40~49개` |
| **산출(운영 시)** | 기간 내 공급내역에 나타난 **고유 품목명** 수 (기업군 집계·비교용) |
| **주의** | 프로필에서 고르는 **품목군**(분류, 시안 기준 11개)과 다름. 품목군은 필터이고, 이 지표는 취급 **품목명** 수 |
| **왜 품목명인가** | 품목군은 종류가 적어(시안 11개) 폭 지표로 쓰기 어렵고, 품목명 수가 실제 취급 다양성을 더 잘 보여 줌 |

### 4.6 거래처 폭

| 항목 | 설명 |
|------|------|
| **의미** | 해당 기업군이 거래한 **거래처(상대 업체) 수** |
| **표시** | 예: `20~29개` |
| **산출(운영 시)** | 기간 내 공급내역의 고유 거래처(내부 업체 일련번호·거래처 코드 기준) 수 |
| **주의** | 업종 유형 수(제조·수입·판매·의료기관 등 4~5개)가 아님. **업체 수** |
| **왜 거래처 수인가** | 업종 유형은 가짓수가 너무 적어 폭 지표로 변별력이 거의 없음 |

### 4.7 공급 수량 방향

| 항목 | 설명 |
|------|------|
| **의미** | 최근 총 공급 수량이 늘었는지·보합인지·줄었는지의 **방향** |
| **표시** | 증가 / 완만한 증가 / 보합 / 감소 등 문구 |
| **산출(운영 시)** | 최근 3개월 공급수량 합과 직전 3개월 합을 비교해 방향 구간으로 요약 |
| **주의** | 금액·시장점유율과 동일하지 않음. 수량 필드가 비거나 이상치면 정제 후 집계 |

### 4.8 월별 거래 활동 추이 (차트)

| 선 | 의미 | 산출(운영 시) |
|----|------|----------------|
| **실선** | 내가 고른 조건(업종·권역·품목군) 기업군의 **월별 평균** 거래 보고 건수 | 해당 월·해당 기업군 소속 기업의 보고 건수 평균 |
| **점선** | 같은 **업종·권역** 전체의 **중앙값** (품목군 조건 제외 기준선) | 같은 업종·권역 기업의 월별 건수 중앙값 |

**읽는 법:** 실선이 점선 위에 있으면 “같은 동네 기준선보다 활동이 많은 달”로 읽습니다. 이력이 짧으면 차트를 숨깁니다.

### 4.9 공급자 집중도 (HHI)

전문가에게 가장 많이 묻는 지표입니다.

| 항목 | 설명 |
|------|------|
| **화면 이름** | 공급자 집중도 (0~1에 가까운 값 → 화면에서는 **낮음 / 보통 / 높음**) |
| **의미** | 한 품목군(또는 품목명)의 공급이 **소수 공급자에게 얼마나 몰렸는지** |
| **산출(운영 시)** | Herfindahl–Hirschman Index (HHI) |

**계산식**

기간(예: 최근 12개월 또는 화면 기준 기간) 동안 해당 품목군·품목명의 공급수량(또는 승인된 집계 단위)을 공급자별로 나눕니다.

\[
s_i = \frac{\text{공급자 } i \text{의 공급량}}{\text{전체 공급량}},\quad
\mathrm{HHI} = \sum_{i=1}^{N} s_i^{2}
\]

- 공급자가 많고 점유율이 고르면 → HHI **작음** (다양)  
- 소수 공급자가 대부분을 차지하면 → HHI **큼** (집중)

**화면 구간(시안 기준)**

| HHI | 표시 |
|-----|------|
| ≤ 0.15 | 낮음 (공급자 다양에 가깝) |
| 0.15 초과 ~ 0.25 | 보통 |
| > 0.25 | 높음 |

**질문 대비**

- 모델 2의 **위험점수·등급**이 아닙니다.  
- “이 시장이 나쁜가?”가 아니라 **“조달·경쟁 구조를 볼 때 공급이 한쪽으로 몰렸는가?”** 입니다.  
- 투자·진입 추천이 아닙니다.

### 4.10 최근 거래 활동 증감률 (검토 지도 Y축)

| 항목 | 설명 |
|------|------|
| **의미** | 품목군별 최근 거래 활동의 증감 (%) |
| **산출(운영 시)** | 품목군 단위로 4.4와 같은 방식의 기간 대비 변화율 |
| **지도에서의 역할** | 위쪽 = 최근 증가, 아래쪽 = 최근 감소 |

---

### 4.11 공급자 수 · 거품 크기 (검토 지도)

| 항목 | 설명 |
|------|------|
| **의미** | 해당 품목군에 공급 실적이 있는 **고유 공급자 수** |
| **거품 구간(시안)** | 소 &lt; 15 · 중 15–34 · 대 ≥ 35 |
| **표시 밴드** | 예: `10~19개` |
| **산출(운영 시)** | 기간 내 해당 품목군 공급내역의 고유 공급자 일련번호 수 |

**지도 한눈에**

- **가로(X):** 공급자 집중도 (왼쪽 낮음 → 오른쪽 높음)  
- **세로(Y):** 최근 증감률  
- **거품:** 공급자 수(소·중·대)  

“기회 지도”가 아니라 **검토할 품목군을 고르는 지도**입니다.

### 4.12 품목명 통계에서 추가로 보는 지표

| 지표 | 의미 | 산출(운영 시) |
|------|------|----------------|
| **활동 증감** | 해당 품목명의 최근 거래 활동 변화 | 품목명 단위 변화율 → 구간 표시 |
| **공급자 집중도** | 품목명 단위 HHI | 4.9와 동일, 집계 단위만 품목명 |
| **공급자 규모** | 공급자 수 밴드 | 4.11과 동일 |
| **품목군 내 비중** | 소속 품목군 활동 중 이 품목명이 차지하는 대략 비중 | \(\frac{\text{품목명 활동}}{\text{품목군 활동}}\) → 구간화 |
| **수요처(거래처) 구성** | 의료기관·판매(임대) 등 비중 | 공급받는 자 업종 비율 |
| **월별 추이** | 실선 = 품목명 평균, 점선 = **소속 품목군** 평균 | 월별 보고 건수(또는 승인 집계) 평균 |
| **취급 맥락 비중** | 추적관리·이식·일회용·급여 등 **집계 비중** | 해당 플래그 품목의 공급 비중 구간 (허가 조회 아님) |

### 4.13 진단 (관측 · 해석 · 유의점)

| 구분 | 내용 |
|------|------|
| **관측** | 화면에 나온 숫자·구간을 문장으로 요약 (사실) |
| **해석** | 그 패턴을 어떻게 읽을 수 있는지 (추정, 규칙 기반) |
| **유의점** | 한계·비보장·추가 확인 안내 |

**산출 방식:** LLM이 임의 권고를 만들지 않습니다. **표시된 집계 패턴에 맞춘 규칙**으로 문장을 고릅니다.

---

### 4.14 확인할 질문

표시된 성장·집중도·권역 규모 등에 묶인 **점검용 질문**입니다.  
사업 성과를 보장하는 컨설팅 문구가 아닙니다.

---

### 4.15 기업군 유형 참고

| 항목 | 설명 |
|------|------|
| **의미** | “이런 특성이 자주 같이 보인다”는 **참고 유형** |
| **현재 시안** | 설명용 예시 이름·특징 (실제 군집 결과 아님) |
| **운영 시(계획)** | 품목·거래처·권역 구성 비율 등을 표준화한 뒤 군집 분석 → 최소 크기·안정성 검증 후만 공개 |
| **주의** | `cluster_2` 같은 알고리즘 번호를 쓰지 않고, 의미 있는 이름만 노출 |

기본 약속은 **선택 조건의 해당 기업군 집계**입니다. 유형은 부가 참고입니다.

## 5. 자주 묻는 질문 (지표·해석)

**Q. HHI가 높으면 위험한가요?**  
A. 이 화면에서는 **위험등급이 아닙니다.** “공급이 소수에게 몰린 구조”를 볼 때 쓰는 집중도입니다. 대체 조달·보고 변화를 점검할 **힌트**로만 쓰세요.

**Q. 상위 25%면 우리 회사가 잘한다는 뜻인가요?**  
A. 아닙니다. 공개 화면은 개별 회사가 아니라 **해당 기업군 집계**입니다. 위치 구간은 그 집계가 **전체(넓은 비교 분모) 대비** 어디인지를 뜻하며, “잘함/못함” 평가가 아닙니다.

**Q. 거래 활동과 공급 수량이 다르면 무엇을 믿나요?**  
A. 둘 다 다른 측면입니다. **건수(활동)** 는 보고·거래 빈도, **수량** 은 물량 방향입니다. 한쪽만으로 시장 전체를 단정하지 마세요.

**Q. 실선이 점선보다 높은데 왜 위치는 중간인가요?**  
A. 추이 차트는 **월별 흐름 비교**, 위치 구간은 **기간 요약 지표의 기업군 내 상대 위치**입니다. 시점·집계 단위가 다를 수 있습니다.

**Q. 품목군을 바꿨는데 숫자가 비슷해 보입니다.**  
A. 간담회용 시안은 이해를 위한 **예시 데이터**라 민감도가 실제 운영보다 약할 수 있습니다. 운영 시에는 조건별로 집계가 다시 계산되어야 합니다.

**Q. 모델 2와 뭐가 다른가요?**  
A. 모델 2는 시계열·위험지표·위험점수/등급 중심(관리·시장 안정성). 모델 3는 **기업 이용자용 동종 비교·검토 질문·품목 통계**입니다. 집중도(HHI) 용어가 겹칠 수 있으나, 여기서는 위험등급으로 쓰지 않습니다.

**Q. 모델 1과 뭐가 다른가요?**  
A. 모델 1은 유통 **네트워크·이상(관계 AI) 점수**. 모델 3는 회사명 검색·네트워크 수사가 없습니다.

**Q. 왜 우리 회사 정확한 값을 안 보여 주나요?**  
A. 공개 모드에서는 개별 업체 식별·영업비밀 노출을 막기 위함입니다. 향후 인증된 **「내 회사」** 모드는 별도 권한·개인정보 검토가 필요합니다.

**Q. 이 숫자로 신규 품목 투자를 결정해도 되나요?**  
A. 안 됩니다. 검토용 집계이며 예측·투자 권고가 아닙니다.

2. 확인할 사항  
3. 품목군 변화 지도

5. 품목명 통계

## 7. 한 페이지 요약 (출력·안내용)

1. 업종·권역·**품목군** 선택 → 기업군 리포트  
2. **거시 → 사실 → 진단** 순으로 읽기  
3. 지도에서 **집중도(가로) · 증감(세로) · 공급자 수(거품)** 구분  
4. 필요 시 **품목명** 통계 (색인 아님)  
5. 숫자는 **구간·집계**이며, HHI는 **위험등급이 아닌 집중도**  
6. 예시 데이터이므로 **의사결정에 사용하지 않음**
