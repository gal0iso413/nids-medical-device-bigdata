# 모델 1 「유통 관계 확인」 이용 안내

> **대상:** 유통·감시 업무 담당자 및 간담회 참석자  
> **화면:** 혁신 시안 `innovation/class1.html` (권장) · 기존안 `class_1/`  
> **데이터:** 현재 프로토타입은 **생성 예시**입니다. 아래 산출 정의는 화면이 말하는 의미와 **향후 운영 시 적용할 계산 방식**을 정리한 것입니다. 표시 수치·점수로 위법·정책 판단을 하지 마세요.

---

## 1. 이 시스템이 하는 일 / 하지 않는 일

| 하는 일 | 하지 않는 일 |
|--------|-------------|
| 특정 **업체**를 찾아 전후 **유통 연결망**을 보여 줌 | 익명 기업군 비교(모델 3) · 시장 위험등급(모델 2) |
| 최근 **3개월** 기준 연결·수량·보고 변화 확인 | 전체 유통망 한 장에 그리기 (가독성·성능상 금지) |
| **관계 AI 점수**로 “확인 필요 업체” 우선순위 제시 | 위법·사기·확정 이상 판정 |
| **관찰된 사실 / 모형 해석 / 확인할 질문**을 분리 제시 | “이 연결이 점수에 몇 % 기여했는지” 같은 GNN 속성별 근거(XAI) |

한 줄로: **「이 업체 주변 네트워크에서, 무엇을 먼저 눈으로 확인할지」** 를 돕는 화면입니다.

**모델 1 핵심 키워드:** 관계 AI 점수(GNN) + 연결망 시각화

간담회 기본 예시 업체: **`C 유통`**

## 3. 이용 순서

### 혁신 시안 (권장)

| 단계 | 화면 | 할 일 |
|------|------|--------|
| 01 | 위치 확인 | 업체 검색·선택 → 케이스 요약(연결 수·상태) |
| 02 | 변화 이해 | 최근 3개월에 생긴 연결·수량 변화 카드 확인 |
| 03 | 연결망 | 1·2단계 펼치기, 선 굵기, 공급받음/공급함 표 |
| 04 | 확인할 사항 | 관계 AI 점수 순 목록 → 사실·해석·질문 읽기 |

**「내 업체 보기」:** 다른 노드를 탐색한 뒤, 시나리오상 로그인 업체(예: C 유통) 중심 화면으로 돌아갑니다.

### 기존안

같은 내용을 한 페이지에 스크롤로 배치합니다.

1. 업체 검색 · 3개월 기준 기간  
2. 선택 업체 위치(요약 지표)  
3. 연결망과 최근 변화 · 주요 연결 관계 표  
4. 확인할 사항(관계 AI 점수 목록) · 선택 업체 확인 근거  

상세 설정에서 **연결 범위(1·2단계)** 와 **선 굵기(보고 횟수 / 공급 수량)** 를 바꿉니다.

### 권장 체험 흐름 (3~5분)

1. `C 유통` 검색·선택  
2. 공급받음 / 공급함 업체 수와 **화살표 방향** 확인  
3. 선 굵기를 **공급 수량**으로 바꿔 보기  
4. 연결을 **2단계**까지 펼치기  
5. 「확인 필요」 업체를 열어 **사실 · 해석 · 질문** 구분하기  
6. 「내 업체 보기」로 복귀

## 4. 화면 읽는 법 (연결망)

### 4.1 화살표 방향

- 화살표: **공급자 → 공급받은 자**  
- “공급받음” = 이 업체로 **들어오는** 연결  
- “공급함” = 이 업체에서 **나가는** 연결  

### 4.2 노드(원)

| 표현 | 의미 |
|------|------|
| **색** | 업종 구분 (제조사 · 수입사 · 유통사 · 의료기관) |
| **크기** | 연결 업체 수(연결도)가 클수록 크게 |
| **테두리·표식** | 선택 업체 / **확인 필요** 업체 (색만으로 구분하지 않음) |

### 4.3 선(엣지)

| 설정 | 의미 |
|------|------|
| 선 굵기 = **거래 보고 횟수** | 해당 기간 관계의 보고 건수가 많을수록 굵게 |
| 선 굵기 = **공급 수량** | 공급수량이 많을수록 굵게 |

보고 횟수와 수량은 다를 수 있습니다. 둘 다 본 뒤 해석하세요.

### 4.4 연결 범위

| 범위 | 의미 |
|------|------|
| **1단계** | 선택 업체와 직접 연결된 상대만 |
| **2단계** | 그 상대와 다시 연결된 한 단계 더 (다단계 경로 맥락) |

전체 네트워크를 한 번에 그리지 않습니다. **선택 업체 중심의 제한된 부분 그래프**만 표시합니다.

## 5. 지표(인덱스) 사전 — 의미와 산출

### 5.1 공통 원칙

1. 집계·연결은 **공급내역 보고**를 기준으로 합니다. (프로토타입은 합성값)  
2. 기간은 **3개월 롤링 창**입니다. (예: 2026년 3~5월)  
3. **관계 AI 점수 ≠ 위법 확률.** 확인할 **우선순위**입니다.  
4. 모델 1 화면의 “확인 필요” 정렬은 **관계 AI 점수만** 사용합니다.  
5. 현재 파이프라인에는 GNN **속성별 기여(XAI)** 가 없어, 「가장 큰 근거 %」 문장은 제공하지 않습니다.

---

### 5.2 3개월 기준 기간

| 항목 | 설명 |
|------|------|
| **의미** | 연결·건수·수량을 묶어서 보는 **앵커 기간** |
| **산출(운영 시)** | 선택한 종료월 기준 직전 3개월 공급내역을 집계. 기간을 바꾸면 그래프·표가 다시 계산됨 |
| **질문 대비** | “연간 누적”이 아님. 짧은 창의 스냅샷 |

---

### 5.3 공급받음 / 공급함 업체 수

| 항목 | 설명 |
|------|------|
| **의미** | 선택 기간·연결 범위 안에서, 이 업체로 들어오거나 나가는 **고유 상대 업체 수** |
| **산출(운영 시)** | 방향별 고유 거래 상대(내부 업체 일련번호) 수 |
| **주의** | 보고가 누락되거나 의료기관 식별코드가 비어 있으면 경로가 짧아지거나 끊길 수 있음 |

---

### 5.4 거래 보고 횟수

| 항목 | 설명 |
|------|------|
| **의미** | 해당 관계(또는 업체 합계)에서 공급내역이 **보고된 횟수** |
| **산출(운영 시)** | 기간 내 해당 공급자–공급받은자(·품목) 조합의 보고 건수 합 |
| **주의** | 매출·금액과 동일하지 않음. 보고 습관에 영향받음 |

---

### 5.5 공급 수량

| 항목 | 설명 |
|------|------|
| **의미** | 보고된 **공급 수량**의 합 |
| **산출(운영 시)** | 기간 내 수량 필드 합(이상치·결측 정제 후) |
| **주의** | 금액·시장점유율과 다름. 선 굵기를 수량으로 바꾸면 “많이 움직이는 관계”가 강조됨 |

---

### 5.6 연결도(노드 크기)

| 항목 | 설명 |
|------|------|
| **의미** | 해당 업체가 기간 그래프에서 가진 **연결(간선) 수** |
| **산출(운영 시)** | 선택 기간 부분 그래프에서 해당 노드의 차수(degree: 들어오고 나가는 연결 합) |
| **시안** | 원 크기는 연결 업체 수에 비례 |

“허브처럼 보인다”는 **구조적 사실**이지, 그 자체로 이상은 아닙니다.

---

### 5.7 주요 품목

| 항목 | 설명 |
|------|------|
| **의미** | 해당 관계에서 보고가 많은(또는 대표) 품목 라벨 |
| **산출(운영 시)** | 관계별 품목 집계 상위 항목 |
| **주의** | 전체 취급 목록·허가 색인이 아님 |

### 5.8 관계 AI 점수 (GNN) — 핵심 지표

전문가에게 가장 많이 묻는 지표입니다.

| 항목 | 설명 |
|------|------|
| **화면 이름** | 관계 AI 점수 (0~100) |
| **의미** | 연결 패턴·업체 특성을 학습한 모형이, **비슷한 역할의 업체와 얼마나 다른지**를 점수로 요약한 값 |
| **용도** | 「확인 필요 업체」 **정렬·우선순위** |
| **아닌 것** | 위법 확률, 사기 확률, 확정 이상 판정, BC(중심성) 순위와 동일 개념 |

**산출(운영 시 — 개념)**

1. 공급내역으로 **방향 있는 거래 그래프**(업체=노드, 공급=간선)를 만듭니다.  
2. **그래프 신경망(GNN)** 등이 노드·이웃 연결 구조를 학습합니다.  
3. “비슷한 업종·역할 패턴”과 비교해 **이례 정도**를 점수로 산출합니다.  
4. 화면용으로 **0~100 구간**으로 정규화합니다.  

**시안(프로토타입)에서의 예시 생성**

데모 점수는 학습된 실모형 출력이 아니라, 연결도·업종 등을 섞어 만든 **예시 점수**입니다.  
운영 시에는 실제 GNN/이상탐지 파이프라인 점수로 교체되어야 합니다.

**상태 구간(시안 기준)**

| 관계 AI 점수 | 상태 라벨 | 읽는 법 |
|--------------|-----------|---------|
| ≥ 75 | 우선 확인 | 먼저 연결망·사실을 볼 후보 |
| 50~74 | 관찰 | 여유를 두고 지켜볼 후보 |
| &lt; 50 | 일반 | 목록 우선순위는 낮음 |

**질문 대비**

- “90점이면 90% 확률로 위법?” → **아니요.**  
- “점수가 높으면 자동으로 제재?” → **아니요. 사람이 확인합니다.**  
- “왜 높은지 속성 %로 설명해 달라” → **현재 XAI 없음.** 연결 사실·질문으로 보완합니다.

### 5.9 확인 근거 패널 (사실 · 해석 · 질문)

| 구분 | 내용 | 산출 |
|------|------|------|
| **관찰된 사실** | 연결 수, 경로 길이(직접/다단계), 기간 내 패턴 등 **관측 가능한 서술** | 그래프·집계에서 읽히는 사실 |
| **관계 AI 해석** | “비슷한 역할 대비 구조가 다르게 보인다” 등 **모형 관점 문장** | 점수·시나리오에 맞춘 해석 (확정 아님) |
| **확인할 질문** | 현장에서 이어서 볼 **중립적 질문** | 규칙/템플릿 (권고·유죄 단정 아님) |

이 세 칸을 섞어 읽지 마세요. **사실 ≠ 해석 ≠ 할 일.**

## 6. 화면에 안 나오는 지표 (전문가 FAQ용)

회의·명세에서는 아래 지표가 **근거 가족**으로 언급될 수 있습니다.  
**현재 모델 1 UI는 확인 목록 정렬에 이들을 합치지 않고, 관계 AI 점수만 사용합니다.**

| 지표 | 한 줄 의미 | 왜 안 보이나 |
|------|------------|--------------|
| **BC (Betweenness Centrality)** | 다른 업체 사이를 잇는 경로에 얼마나 자주 끼는지(허브성) | 구조 허브 뷰와 GNN을 **같은 순위로 오해**하지 않게 분리 |
| **PDI** | 품목 기준 경로가 얼마나 긴지(우회·다단계) | Model 1 화면 단순화; 필요 시 사실 문장으로만 언급 |
| **HHI** | 특정 병원–품목 등에서 공급 집중도 | 모델 2·3와 혼동 방지; Model 1 정렬에 미사용 |
| **가격 차이 (robust z)** | 동일 품목·공급유형 대비 가격 이례 | 정렬에 미사용 |
| **보고 시차** | 공급일 vs 최초 접수일 지연 | 정렬에 미사용 |

운영 고도화 시 GNN과 **약한 베이스라인**으로 비교할 수는 있으나, 간담회 시안에서는 **점수=관계 AI만**이라고 안내하세요.

## 7. 자주 묻는 질문

**Q. 관계 AI 점수가 높으면 이상거래인가요?**  
A. 아닙니다. **확인 우선순위**입니다. “확인 필요”는 불법·확정 이상을 뜻하지 않습니다.

**Q. GNN이 뭔가요?**  
A. **관계(연결) 구조를 학습하는 AI**입니다. 표만 보는 모형과 달리, “누가 누구와 연결되어 있는지”를 함께 봅니다. 참석자 안내에서는 “관계 구조를 학습하는 AI”로 말해도 됩니다.

**Q. 왜 속성별 기여(설명)가 없나요?**  
A. 현재 파이프라인에 GNN 전용 XAI가 없습니다. 대신 **관찰된 사실**과 **확인할 질문**으로 보완합니다.

**Q. BC와 관계 AI 점수가 같은가요?**  
A. **다릅니다.** BC는 경로상 허브 지표, 관계 AI는 학습된 이례 점수입니다. Model 1 목록은 GNN만 씁니다.

**Q. 화살표가 어느 쪽인가요?**  
A. **공급자 → 공급받은 자**입니다.

**Q. 1단계와 2단계 차이는?**  
A. 1단계는 직접 거래 상대, 2단계는 그 상대의 상대까지입니다. 다단계 유통 맥락을 볼 때 2단계를 켭니다.

**Q. 선 굵기를 바꾸면 점수도 바뀌나요?**  
A. **아니요.** 선 굵기는 시각화만 바꿉니다. 관계 AI 점수는 별도 산출입니다.

**Q. 모델 2·3와 뭐가 다른가요?**  
A. 모델 1 = **특정 업체 네트워크 + 관계 AI 우선순위**. 모델 2 = 시계열·위험지표·등급. 모델 3 = 익명 기업군 비교·품목 통계(업체 검색 없음).

**Q. 실제 데이터면 경로가 항상 완전한가요?**  
A. 아닙니다. 의료기관 식별코드 결측 등으로 **일부 경로가 불완전**할 수 있습니다. 한계 목록을 함께 보세요.

**Q. 이 점수로 제재·수사 결정을 해도 되나요?**  
A. **안 됩니다.** 예시 데이터이며, 점수는 확률·증거가 아닙니다.

## 8. 한 페이지 요약 (출력·안내용)

1. 업체 검색 → **3개월** 창에서 위치 확인  
2. 화살표 = **공급자 → 공급받은 자**, 원 크기 = 연결 수  
3. 선 굵기 = 보고 횟수 또는 공급 수량 (시각화만)  
4. **관계 AI 점수** = 확인 우선순위 (0~100), **위법 확률 아님**  
5. 근거는 **사실 / 해석 / 질문**으로 나눠 읽기  
6. BC·가격·시차 등은 **이 화면 정렬에 합치지 않음**  
7. 예시 데이터 → **운영 판단에 사용하지 않음**
