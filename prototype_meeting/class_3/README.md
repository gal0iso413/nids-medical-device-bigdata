# Class 3 Meeting Prototype

## Demonstration flow (3–5 minutes)

1. Select `판매·임대업체`, `수도권`, `환자감시·생체계측`, and `중간 규모`.
2. Confirm how the anonymous comparison cohort is defined.
3. Read the range-based peer metrics and monthly trend.
4. Open “품목 변화 지도” and identify growth and concentration.
5. Open “비슷한 기업군” and check whether the descriptions are meaningful.
6. Choose one question in “확인할 사항.”
7. Review which firm-level fields are intentionally hidden.

## Data contract

`data/mock_data.json` is generated by `build_mock_data.py`. It contains only
synthetic:

- profile options
- business-type scenarios
- cohort-size examples
- monthly aggregate series
- percentile-band metrics
- product growth/concentration records
- semantic similar-group profiles
- privacy and limitation text

## Production boundary

The current Class 3 analytical code remains a product-group MCDM/Kraljic Phase
1 explorer. This prototype does not implement production firm clustering,
redaction, or publication.

Before a production public service:

- approve a revised Class 3 specification and phase advancement
- build firm-month aggregate data products
- validate cohort or cluster stability
- implement server-side small-cell, dominance, and differencing controls
- complete NIDS privacy/legal review
