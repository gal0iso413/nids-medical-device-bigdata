# Class 3 Meeting Prototype

## Pages

- **기존안:** [`index.html`](./index.html) — tabbed cohort dashboard
- **혁신 시안:** [`../innovation/class3.html`](../innovation/class3.html) — firm-first report, then 의료기기 품목명 statistics sequel

## Control demo flow (4–6 minutes)

Aligned with the facilitation guide (Tasks 1–4; sparse optional).

1. Select `판매(임대)업`, `수도권`, and a **품목군** (e.g. `B2. 임상화학검사기기`).
2. Read **거시 → 쉬운 사실 → 진단** (privacy one-liner under diagnosis).
3. Use **품목군 검토 지도 보기** (map opens by default): x = 공급자 집중도, y = 증감률, bubble = 공급자 수(소·중·대).
4. Click **관심 의료기기 알아보기** (also under diagnosis) → pick a **품목명** from 추천 검색어 (e.g. `체외형 범용 프로브`).
5. Read 품목명 **statistics** (not an index card; 취급 맥락 is collapsed).
6. *(Optional)* Sparse: `기타`+`비수도권` suppress · `기타`+`수도권` thin history.

## Map legend

- **X:** 공급자 집중도 (HHI 낮음→높음)
- **Y:** 최근 거래 활동 증감률 (%; includes negative ticks)
- **Bubble:** 공급자 수 — 소 &lt;15 · 중 15–34 · 대 ≥35 (on-chart legend)

## 품목군 vs 품목명

- Firm profile uses **품목군**.
- Device sequel (혁신 only) uses **품목명**.
