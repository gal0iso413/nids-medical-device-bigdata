## Control demo flow (4–6 minutes)

Aligned with the facilitation guide (Tasks 1–4; sparse optional). Prefer **혁신 시안** for Top-down guidance; 기존안 can run the same sequel via tabs.

### 혁신 시안

1. Select `판매(임대)업`, `수도권`, and a **품목군** (e.g. `B2. 임상화학검사기기`).
2. Read **거시**(지표 + 월별 변화) → **진단** (privacy one-liner under diagnosis).
3. Use **품목군 검토 지도 보기** (map opens by default): x = 공급자 집중도, y = 증감률, bubble = 공급자 수(소·중·대).
4. Click **관심 의료기기 알아보기** → pick a **품목명** from 추천 검색어 (e.g. `체외형 범용 프로브`).
5. Read 품목명 **statistics** (not an index card; 취급 맥락 is collapsed).
6. *(Optional)* Sparse: `기타`+`비수도권` suppress · `기타`+`수도권` thin history.

### 기존안 (tab sequel)

1. Same profile → **해당 기업군 보기**.
2. Overview CTA **관심 의료기기 알아보기** (or tab **품목명 통계**).
3. Chip / search → **품목 통계 보기** → diagnosis.
4. Suppress hides the result panel and disables the 품목명 tab.

## Map legend

- **X:** 공급자 집중도 (HHI 낮음→높음)
- **Y:** 최근 거래 활동 증감률 (%; includes negative ticks)
- **Bubble:** 공급자 수 — 소 &lt;15 · 중 15–34 · 대 ≥35 (on-chart legend)

## 품목군 vs 품목명

- Firm profile uses **품목군**.
- Device sequel uses **품목명** (both pages). Mock catalog covers A1–A3, B1–B7, C.
