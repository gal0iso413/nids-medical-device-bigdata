# Class 3 Meeting Prototype

## Pages

- **기존안:** [`index.html`](./index.html) — tabbed cohort dashboard
- **혁신 시안:** [`../innovation/class3.html`](../innovation/class3.html) — editorial peer briefing lab

## Control demo flow (3–5 minutes)

1. Select `판매·임대업체`, `수도권`, and a product group.
2. Confirm how the anonymous comparison cohort is defined.
3. Read the range-based peer metrics and monthly trend.
4. Open “품목 변화 지도” and identify growth and concentration.
5. Open “비슷한 기업군” and check whether the descriptions are meaningful.
6. Choose one question in “확인할 사항.”
7. Review which firm-level fields are intentionally hidden.

## Data contract

`data/mock_data.json` is generated by `build_mock_data.py`. Synthetic profile
options, scenarios, bands, and privacy text only.

## Production boundary

This prototype does not implement production firm clustering, redaction, or
publication. Privacy/legal review is required before any public service.
