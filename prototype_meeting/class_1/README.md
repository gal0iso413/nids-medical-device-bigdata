# Class 1 Meeting Prototype

## Demonstration flow (3–5 minutes)

1. Search `C 유통`.
2. Confirm incoming/outgoing organization counts and the arrow direction.
3. Change line thickness from report count to supplied quantity.
4. Expand from one to two connection steps.
5. Select “내 업체 보기” after exploring another node.
6. Open an organization in “확인 필요 업체.”
7. Read the observed fact, model interpretation, review question, and one
   limitation.

## Data contract

`data/mock_data.json` is generated by `build_mock_data.py` and is fully
synthetic. It includes:

- masked entities and organization types
- monthly edge report counts and quantities
- illustrative GNN scores for review ordering
- neutral evidence and review-question text (no per-factor XAI)

The prototype does not use source workbooks at runtime.

## Analytical correspondence

- review list → GNN anomaly score priority (Model 1 UI uses GNN only)
- 내 업체 보기 → return to session focal company (demo: C 유통)
- period → three-month rolling window

GNN scores are meeting scenarios; production has no attribute-level XAI yet.
